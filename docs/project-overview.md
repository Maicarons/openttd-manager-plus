# 项目介绍

> OpenTTD Manager Plus 是一个跨平台的开源 OpenTTD 版本管理器与启动器。它旨在为 OpenTTD 玩家提供一站式的版本管理、模组管理、配置管理和游戏启动体验。

## 项目背景

OpenTTD 是一款经典的开源模拟经营游戏，拥有活跃的社区和多个分支版本：

- **官方 OpenTTD** — 稳定主线版本
- **JGRPP** — JGR 的补丁包版本，增加大量新特性
- **CityMania Client (CMClient)** — 面向联机服务的客户端
- 以及其他社区 fork

然而，目前缺乏一个统一的工具来管理这些版本、它们的配置文件、模组和资源。玩家需要手动下载、解压、维护不同版本的配置文件，过程繁琐且容易出错。

## 项目目标

1. **一键管理多版本** — 像 Minecraft 启动器一样，自动检测、下载、切换 OpenTTD 各版本
2. **智能配置隔离** — 每个版本可使用独立配置，也可共享基础配置
3. **模组生态集成** — 内置在线模组浏览器，支持 NewGRF、AI、GameScript、音轨集
4. **镜像加速** — 针对国内用户自动选择最优下载源
5. **跨平台覆盖** — 桌面端全覆盖，移动端支持 Android APK 和 iOS IPA 管理

## 核心价值

| 场景 | 当前痛点 | OTTD Manager Plus 解决 |
|------|---------|----------------------|
| 多版本需求 | 手动下载解压，管理混乱 | 一键安装、切换，版本隔离 |
| 联机需要特定版本 | 找版本、找启动参数麻烦 | 版本列表+参数预设 |
| 国内下载慢 | 从 GitHub 下载缓慢 | 自动镜像加速 |
| 整理模组 | 手动复制到文件夹 | 图形化模组管理 |
| 移动端游玩 | 找不到合适的版本 | 内置 APK/IPA 下载管理器 |

## 适用人群

- OpenTTD 普通玩家
- 联机玩家（需要特定版本）
- 模组制作者（需要测试多版本）
- 移动端玩家（Android APK / iOS 版本管理）
- 国内用户（需要加速下载）
