# 启动器

> 启动器核心负责准备环境并启动 OpenTTD 游戏进程。

## 启动流程

```
┌─────────────────────────────────────┐
│         用户点击"启动"               │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│      1. 版本验证                    │
│     - 检查版本文件完整性            │
│     - 检查可执行文件存在            │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│      2. 配置准备                    │
│     - 加载配置方案                  │
│     - 生成 openttd.cfg（如需要）    │
│     - 设置环境变量                  │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│      3. 参数构建                    │
│     - 基础参数（-D, -g 等）         │
│     - 配置路径参数                  │
│     - 用户自定义参数                │
│     - 联机参数（如需要）            │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│      4. 进程启动                    │
│     - 设置工作目录                  │
│     - 启动游戏进程                  │
│     - 监控进程状态                  │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│      5. 运行中                      │
│     - 显示运行状态                  │
│     - 等待进程退出                  │
│     - 捕获退出代码                  │
└─────────────────────────────────────┘
```

## 启动参数构建

### 基础参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `-D<dir>` | 数据目录 | `-D/home/user/.openttd/instances/14.1` |
| `-c<file>` | 配置文件 | `-c/home/user/.openttd/openttd.cfg` |
| `-g<file>` | 启动时加载存档 | `-gsave/autosave.sav` |
| `-n<host>` | 联机连接 | `-nserver.openttd.org` |
| `-p<pass>` | 联机密码 | `-psecret` |

### 参数模板

- **单机模式** — 基础参数 + 数据目录
- **联机模式** — 基础参数 + 服务器地址 + 密码
- **调试模式** — 基础参数 + `-d` (debug) 标志
- **自定义模板** — 用户可保存自定义参数集

## 多实例运行

- 支持同时启动多个 OpenTTD 实例
- 每个实例独立工作目录和配置
- 实例间互不干扰
- 进程管理面板显示所有运行实例

## 进程监控

- 实时 CPU / 内存占用显示
- 进程状态（运行中 / 无响应 / 已退出）
- 强制终止功能
- 崩溃检测和异常退出通知
