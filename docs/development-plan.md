## 资源需求

### 开发环境

| 工具 | 版本 | 用途 |
|------|------|------|
| Rust | 1.80+ | 编译语言 |
| Cargo | 最新 | 包管理/构建 |
| Dioxus CLI (`dx`) | 0.7 | 构建/打包/热重载 |
| Node.js | 22+ | 文档系统 |
| Android SDK | 35 | Android 构建 |
| Xcode | 16+ | iOS 构建 |

| macOS 15 | Mac Mini / 虚拟机 |
| Android 15 | 实机 + 模拟器 |
| iOS 19 | 实机 + 模拟器 |

## 风险与缓解

| 风险 | 影响 | 可能性 | 缓解措施 |
|------|------|--------|---------|
| Dioxus 版本不稳定 | 高 | 低 | 锁定 0.7 稳定版，及时跟进修复 |
| Android 构建复杂 | 中 | 中 | 早期搭建 CI，利用 `dx` CLI 简化 |
| iOS 构建需 macOS | 中 | 高 | CI 使用 macOS runner，本地需 Mac |
| Blitz 原生渲染器兼容性 | 中 | 低 | 标准化测试矩阵，覆盖不同 GPU 厂商 |
| 社区贡献不足 | 低 | 中 | 完善文档，降低贡献门槛 |
| OpenTTD 版本源变更 | 高 | 低 | 抽象版本源接口，快速适配 |
| GPU 驱动兼容性 | 低 | 中 | Blitz 通过 WGPU 抽象层，支持 D3D12/Vulkan/Metal |
