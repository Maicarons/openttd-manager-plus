## 功能优先级

### P0 - 核心功能（MVP 必需）

- [x] 版本管理：官方 OpenTTD + JGRPP 版本列表获取
- [x] 版本安装：下载、解压、完整性验证
- [x] 基础启动器：启动已安装版本
- [x] 镜像加速：自动选择最优镜像
- [x] 配置管理：独立/共享配置方案
- [x] 跨平台桌面：Windows/Linux/macOS

### P1 - 重要功能

- [ ] CMClient 支持
- [ ] 自定义版本导入
- [ ] 配置图形化编辑器
- [ ] 在线模组浏览器
- [ ] 下载队列管理
- [ ] Android 移动端支持
- [ ] iOS 移动端支持
- [ ] 多语言界面

### P2 - 增强功能

- [ ] 存档管理
- [ ] 模组冲突检测
- [ ] 多实例同时运行

- [ ] 配置预设模板
- [ ] 主题系统

### P3 - 远期规划
