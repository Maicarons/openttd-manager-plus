# UI/UX 设计

> 本章描述 OpenTTD Manager Plus 的用户界面和用户体验设计。

## 设计原则

1. **简洁直观** — 清晰的信息层级，减少认知负担
2. **一致性** — 跨平台统一的设计语言
3. **反馈即时** — 操作有即时视觉反馈
4. **容错设计** — 可撤销操作，确认对话框
5. **渐进式** — 基础功能一目了然，高级功能可探索

## 颜色方案

### 浅色模式

| 角色 | 颜色 | 用途 |
|------|------|------|
| 主色 | `#4a9e4a` (绿色) | 按钮、链接、选中状态 |
| 背景 | `#f5f5f5` | 页面背景 |
| 卡片 | `#ffffff` | 卡片背景 |
| 文字 | `#1a1a1a` | 主要文字 |
| 次要文字 | `#666666` | 辅助文字 |
| 边框 | `#e0e0e0` | 分割线、边框 |
| 强调 | `#e67e22` | 下载、更新提示 |
| 危险 | `#e74c3c` | 删除、警告 |

## 字体

| 层级 | 字体大小 | 字重 | 用途 |
|------|---------|------|------|
| H1 | 28px | Bold | 页面标题 |
| H2 | 22px | Bold | 区块标题 |
| H3 | 18px | Semibold | 卡片标题 |
| 正文 | 14px | Regular | 普通文字 |
| 辅助 | 12px | Regular | 描述、标签 |
| 代码 | 13px | Monospace | 配置、路径 |

## 交互反馈

| 操作 | 反馈 |
|------|------|
| 按钮点击 | 缩放动画 (0.95) |
| 列表项点击 | 背景色高亮 |
| 加载 | 骨架屏/Skeleton |
| 后台任务 | Toast 通知 |
| 错误 | 红色错误提示 |
| 成功 | 绿色成功提示 |
| 拖拽 | 拖拽阴影 |
| 开关 | 平滑过渡动画 |
